# 项目 Memory Bank 维护规范

`memory-bank/` 记录项目内、可随代码演进的最小上下文，不替代 Codex 全局记忆。
本文件只规定当前仓库 `memory-bank/**` 的文件职责和维护流程。
Memory Bank 的读取、写入和归档授权由 `AGENTS.md` 决定；本文件不得扩大
授权，也不得降低 `AGENTS.md` 的只读、最小同步和 archive 隔离要求。

## 按需访问

- 仅在当前任务需要时读取对应文件，不得因为目录存在而扫描整个
  `memory-bank/`。
- 访问其他 Memory Bank 文件前先读取本文件；已经在当前任务中完整读取过时
  不重复读取。

| 文件 | 何时读取 | 何时更新 |
|---|---|---|
| `techContext.md` | 改动模块边界、Manifest、存储或消息协议 | 架构/契约变化后 |
| `activeContext.md` | 处理当前限制、兼容性问题或发布阻碍 | 即时约束变化后 |
| `progress.md` | 用户要求查看下一任务 | 已授权任务完成并验证后 |


## `activeContext.md`

- 只记录即时上下文、技术债和阻碍（Blocker）。
- 当已授权任务本身需要写入该文件，且写入前或写入后物理行数超过 150 行时，
  在同次变更中执行最小归档。
- 只读任务中发现超过阈值时仅报告，不执行归档。

## `progress.md`

- 只使用切香肠式 `[ ]` 与 `[x]` 可执行清单。
- 已授权实现任务成功完成并通过对应验证后，勾选与该任务直接对应的项目。
- 已完成项目超过 20 项，且当前任务本身需要写入该文件时，执行最小归档。
- 不得为了勾选进度而修改无关项目或重写历史记录。

## `archive/`

- 归档目录存放按本规范从活动文件中移出的冷冻切片。
- 只有 `AGENTS.md` 已经允许归档维护时，才可以按当前任务指定的最小范围写入。
- 不得把归档维护扩展为历史扫描、内容复盘或无关整理。
